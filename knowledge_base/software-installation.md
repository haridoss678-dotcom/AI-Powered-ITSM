# Enterprise Software Catalogue and Provisioning

## Overview
Employees can request pre-approved software packages directly from the Software Catalogue without requiring manual manager approval for standard non-license-restricted applications.

## Standard Catalogue Packages Available
- **Visual Studio Code**: Code editor for developers with Python, JavaScript, and Docker extension support.
- **Zoom Desktop Client**: Enterprise video conferencing and screen sharing tool.
- **Postman**: API testing and development environment.
- **Python Runtime**: Standard Python 3.11 developer distribution including pip and virtual environment utilities.
- **Google Chrome**: Enterprise managed web browser with corporate security extensions.
- **Adobe Acrobat Reader**: PDF reader and form completion utility.

## How to Request Software
1. Open the **Software Catalogue** screen in the helpdesk portal.
2. Search for the desired application or ask the AI Assistant (e.g. *"I need Visual Studio Code installed on my laptop"*).
3. The system creates a ServiceNow service request record (`REQ...`) and triggers the automated provisioning agent.
4. The provisioning system simulates package delivery and updates the request status to `completed`.

## Non-Catalogue Software Requests
If you require specialized software not listed in the catalogue, submit a custom request specifying business justification, license requirements, and vendor information for Desktop Support review.
